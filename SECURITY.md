# Security Policy

## Supported versions

The project is in pre-release development. Version **1.19.2** is the current documented testing release. Older versions are not guaranteed to receive security updates.

## Reporting a vulnerability

Please **do not post security vulnerabilities, credentials, private files, or exploit details in public issues**.

Contact **brygar.official@gmail.com** with a description of the issue, affected version, reproduction steps, and potential impact. Avoid attaching sensitive user data.

No fixed response or remediation timeframe is guaranteed.
