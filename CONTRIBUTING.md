# Contributing

Thank you for your interest in Chord AI.

## Reporting issues

Before opening a new issue, check whether a similar issue already exists. Include:
- Chord AI version (for example, 1.19.2)
- Android version and device model
- Steps to reproduce
- Expected and actual results
- Screenshots or logs where useful, with private information removed

## Feature requests

Explain the user problem, proposed behavior, and how it would fit the current Android experience.

## Code contributions

Please open an issue to discuss larger changes before submitting a pull request. Keep changes focused, describe testing performed, and avoid unrelated UI changes.

Do **not** submit copyrighted model weights, signing keys, credentials, personal audio files, or other assets you do not have permission to distribute.

There is currently **no repository-wide open-source license**. Public visibility alone does not grant permission to reuse or redistribute the code. Please contact the maintainer before proposing external code contributions that require licensing clarification.
